# mv4 模块接口

《一万个我》MV 的 3D 版：纯代码（three.js），不用任何图片、模型或音效素材。
本文件只写跨模块的约定；模块内部怎么做由各模块自己决定。

## 场景构想：月夜书案

歌里的「毫」本来就是毛笔的毛，歌里反复出现的是纸、字、月光、四季、火。所以整个世界是一张书案：

- 小蟹是书案上的小生灵，只有两三厘米高。镜头贴着案面拍，像微距摄影。
- 铺开的宣纸是舞台，纸上是这首歌的墨迹。笔架山是歌里的「山」，砚台是墨池，能照见月亮。
- 油灯是歌里那团「柴换过了火还亮」的火。梅瓶里一枝梅斜探到纸的上空。
- 案后一架四扇屏风，画着春夏秋冬。月亮在后墙的月洞窗外。
- 分身「落向四方」「下山去」是一只只从纸上起跳、穿过月洞窗飞向窗外；它们带回来的薄纸也从月洞窗飞回来，落到那摞纸上。

这是我们自己的场景，从自己的歌词里长出来。别人的作品只用来对照精细度，不照搬任何内容。

## 美术方向（所有模块共同遵守）

- 国风动画电影的质感：造型细、层次多、上色柔和。**不追求写实**，不要塑料或金属的硬高光。
- 精细度体现在形状、做工和层次上：器物有真实的结构和纹饰，材质有手工的痕迹，近看经得起。
- 微距的尺度感：器物相对小蟹是巨大的。纸有纤维，木有纹理，瓷有开片，铜有锈色，墨有光泽。
- 夜景。冷调的靛紫色月光是主光，暖黄的灯火是点缀。配色取 `src/world/layout.js` 里的 `PAL`。
- 小蟹是平涂加描边的卡通角色；场景不描边，但同样用柔和、偏手绘的上色。
- 画面里一切都是时间的纯函数：同一个时刻永远画出同一帧，可以乱序逐帧渲染。
  随机数用 `src/anim.js` 的 `rnd(n)`，不用 `Math.random()`。
- 写字可以用系统自带的中文字体（例如楷体）画到程序生成的贴图上。

## 坐标和布局

- x 向右，y 向上，z 朝镜头。宣纸的纸面在 y = 0。1 个单位约等于现实里的 1.25 厘米。
- 位置、尺寸、配色、机位全部写在 `src/world/layout.js`，各模块只读不改。
- 镜头多数时候在表演区朝镜头一侧、贴近案面往 -z 方向看；也会绕到器物旁边、升到高处俯拍、推向屏风和月洞窗。
- 表演区（`STAGE`：纸上半径 10.5 的圆）地面以上必须空着，是小蟹表演的地方。
- 镜头和表演区之间（z 大于 4、x 在 ±7 以内）不能有东西挡住；再往两侧可以放前景框住画面。
- 全景机位在表演区那个深度只能看到 x 在 ±12 以内；想被看见的器物要放在表演区后面（z 小于 -11）。

## 场景模块的接口

每个场景模块导出一个函数：

```js
export function build(scene, ctx) { /* 把东西加进 scene */ return { update(t) { /* t：秒 */ }, /* 其他导出 */ }; }
```

- 装配顺序固定：背景 → 书案 → 文房 → 灯火。`ctx` 里有 `renderer`，以及先装的模块导出的东西。
- 可以另外导出 `SHOTS`（和 `layout.js` 里同样的格式），给预览工具加自己的检查机位。

各模块在返回值里额外导出的东西：

| 模块 | 导出 | 说明 |
|---|---|---|
| 背景 | `panels` | 四扇屏风的画心，从左到右春夏秋冬。每项 `{ season, c, w, h, right, up }`：季节、中心、宽、高、画面向右和向上的单位向量（`THREE.Vector3`）。光点会落到画面上 |
| 书案 | `perches` | 小蟹可以站上去的落脚点（`THREE.Vector3` 列表，至少 24 个，在两条镇尺的顶面上，沿长边均匀排开） |
| 文房 | `branchTips` | 梅枝上开花处的位置（`THREE.Vector3` 列表），梅瓣从这些地方飘落 |
| 灯火 | `flame` | 油灯火苗的位置（`THREE.Vector3`） |

- 器物必须摆在 `layout.js` 的 `PROPS` 给出的落脚点上，不超出各自的占地半径。
- 背景模块里屏风的位置、月洞窗的位置按 `layout.js` 的 `SCREEN`、`WALL`、`MOON`。
- 灯火模块单独预览时拿不到 `branchTips`，梅瓣改从 `PROPS.vase` 上方 14 到 20 个单位处飘落；总装时用文房给的真实位置。

## 小蟹的接口

`src/crab.js` 导出：

| 导出 | 说明 |
|---|---|
| `REST` | 默认姿势，列出全部姿势参数 |
| `pose(...parts)` | 把若干组参数叠在 `REST` 上，得到完整姿势 |
| `MOOD` | 眼神的编号：`open`、`joy`、`calm`、`ouch`、`wow`（吃惊）、`star`（星星眼）。切换时自动先眯一下 |
| `KIT_NAMES` | 头饰名字的列表，第一个是主角的 `pin` |
| `Crab` | `new Crab(kit, steps)`；`.root` 是要加进场景的 `THREE.Group`；`.update(poseAt, t)`；`.lips` 是嘴在世界里的位置 |
| `Bond` | 分裂时连着两只小蟹的拉丝。`new Bond()`；`.root` 加进场景；`.update(a, b, u)`，`u` 是这两只分开后的秒数 |

- `update(poseAt, t)`：`poseAt(时刻)` 返回那一刻的姿势。模型会多次调用它回看过去，用来算弹性。
- `src/main.js` 用到的姿势参数：`x y z s yaw sq lean pitch puff blink mood mouth pucker aL aR walk stride`。
  这些参数的名字和含义不能变。可以新增参数，但必须有默认值，不传时表现和现在一样。
- 可选的姿势参数：`look`（视线 [右, 上]）、`wink`（单眨）、`brow`（眉）、`blush`（腮红浓淡）、`cat`（猫嘴）、`laugh`（大笑）、`pull`（被牵的方向和距离）。
- `steps` 小于 30 的小蟹用精简档的网格，人群用这一档。
- `Bond.update` 必须在两只小蟹当帧的 `update` 之后调；不在分开后的 0 到 0.7 秒内它自己隐藏。
- 小蟹只往地面投影，自己不接收投影（平涂才干净）。
- 一场戏同屏最多 56 只小蟹。

## 全片的结构

歌长 202.41 秒。影片的节奏是「书案 → 散出去看外景 → 唱到回来再回书案」，每段主歌、副歌各走一趟。

- 三个场景：书案（室内，`world.js`），和两处外景——山水（`wild.js`）、海边（`shore.js`）。分身从月洞窗飞出去，镜头跟出去就是外景。
- 全片切成若干段，登记在 `src/show/program.js`。时间有重叠时排在前面的优先：外景的段落排在前面，就能从书案的一段中间切出去再切回来。
- 所有时刻都是歌曲里的秒数。歌词的时间在 `src/show/beat.js` 的 `LINES`，字幕由总调度统一画，各段不用管。

### 一段表演的接口

```js
export const span = [开始, 结束];
export function build(kit) { return { frame(t) { /* 说这一帧怎么演 */ return { cam, ... }; } }; }
```

外景的段落另外导出 `outdoor: true`：只装书案时（`desk-only.html`）它们不上场，那段时间由排在后面的书案段落顶上。

`frame(t)` 每帧调一次。它用 `kit` 说这一帧谁上场、哪里有光点和纸（见下），并返回：

| 返回的字段 | 说明 | 不写时 |
|---|---|---|
| `cam` | 镜头：`p` 位置、`q` 看向的点、`f` 对焦距离（离镜头这么远的东西最清楚）、`fov` 视角、`roll` 侧倾的度数、`blur` 虚化加重几倍（前景要虚成色斑、不挡后面的戏时用） | 必写（`fov` 36，`roll` 0，`blur` 1） |
| `set` | 在哪个场景：`'desk'`、`'wild'` 或 `'shore'` | `'desk'` |
| `season` | 山水的季节：`'春'` `'夏'` `'秋'` `'冬'` | 山水必写 |
| `weather` | 山水的天气：1 是这个季节平常的样子，0 是雨雪花叶都停了 | 1 |
| `sunset` | 海边日落的进度：0 落日在海平线上方一截，1 下沿贴到海平线 | 0 |
| `dawn` | 书案的天色：0 月夜，1 清晨 | 0 |
| `lamp` | 油灯的火势：1 正常，0 熄灭，大于 1 更旺 | 1 |
| `fade` | 画面压黑多少（0 到 1） | 0 |
| `paint(g2, W, H)` | 自己往画面上叠的东西（例如片名），画在歌词下面 | 不画 |

- `frame` 必须是时刻的纯函数：不保存上一帧的状态，同一个 `t` 永远得到同一帧。
- 镜头切换就是相邻两帧返回不同的 `cam`；`anim.js` 的 `key()` 里把两个关键帧写在同一时刻就是一次硬切。
- 镜头可以去任何地方，只避开两个穿帮的方向：从书案最右边往左看（屋子左边是空的），和从屏风后面往镜头方向看。

### 共用的家当（`kit`）

每帧开始时全部清空，没被点到的就不出现。

| 名字 | 说明 |
|---|---|
| `kit.hero` | 主角：头上一支簪的那只 |
| `kit.twin` | 和主角一模一样的另一只（昨夜的自己、下一个自己） |
| `kit.full[0..14]` | 15 只戴各种头饰的分身 |
| `kit.lite[0..39]` | 40 只精简档的人群 |
| `kit.act(crab, poseAt)` | 这一帧让这只小蟹上场；`poseAt(时刻)` 返回姿势（会被多次调用回看过去，用来算弹性） |
| `kit.bond(a, b, u)` | 这一帧在两只小蟹之间拉一根丝；`u` 是它俩分开后的秒数 |
| `kit.lights.put(at, size, color)` | 一个光点：位置 `[x, y, z]`、半径、`THREE.Color`（分量大于 1 会泛光）。同屏最多 1200 个 |
| `kit.slips.put({ at, rot, size, kind, ink, glow, curl })` | 一张薄纸，见 `slips.js`。同屏最多 400 张 |
| `kit.puffs.put(spot, age, kind, { s, power, light })` | 落地时脚边带起的一小圈（尘、雪沫、水花、落叶、水沫，见 `puffs.js` 的 `PUFF`）：落点、落地后过了几秒、种类。沿路蹦的小蟹用 `walker` 返回的 `poseAt.landed(t, back)` 取最近的落地 |
| `kit.group()` | 新建一个 `THREE.Group` 放这一段自己的道具；只有轮到这一段时才显示 |
| `kit.groundAt(x, z)` | 书案上这一点最高的表面有多高（小蟹要站到器物上时用） |
| `kit.world` | 书案场景的把手：`panels`、`perches`、`branchTips`、`flame`、`wick` |
| `kit.wild`、`kit.shore` | 两处外景的把手（见下） |
| `kit.seen` | 最近摆好的一帧：`bodies` 上场小蟹的身体，`pushed` 被推开的纸（给穿模检查用） |

- 小蟹的姿势参数见 `src/crab/pose.js`。`ghost: 1` 把整只变成月光色的发光虚影。
- 道具要贴着小蟹的手或嘴时：`hold.js` 的 `handOf(crab, side)` 给手的位置，`crab.lips` 给嘴的位置（都要在它这一帧 `update` 之后取）。
- 薄纸会自动避开小蟹的身体：不是平铺的纸陷进身体时，每帧被往外推到刚好不碰。摆纸时用 `hold.js` 的拿法按身体算位置，就不会被推。
- 同一帧上场的小蟹不超过 56 只。
- 一段自己的道具自己做（放进 `kit.group()`），不改共用的文件；觉得共用的东西需要改，写进交付说明。

### 前后要对得上的东西

各段之间都是硬切，只有下面这些要一致：

| 东西 | 约定 |
|---|---|
| 主角留守的位置 | 纸上 `[x, z] = [0, .9]`，大小 1.15，面朝镜头时 `yaw` 为 0，望月时 `yaw` 为 164 |
| 那摞纸 | 在 `slips.js` 的 `PILE`，用 `drawPile(kit.slips, n)` 画前 n 张 |
| 纸的张数 | 28.6 秒起 44 张；51.2 秒起 90 张；100 秒起 140 张；之后不少于 140 张（140 张摞起来约 1.3 高） |
| 62.3 秒（入睡 → 醒来） | 主角趴在留守点睡着，背上盖着「月很圆」那一页抖开成的布被（`show/quilt.js`，入睡、醒来两段都用 `cover(body)`）；醒来后被子从背上滑下去，摊在身后（中心约 `[0, 0, -3.6]`，x 在 ±3 以内，e 段到 91.2 秒用 `rest()` 画同一个样子）。留言那张纸在枕边左侧，73 秒唱到「只有枕边 昨夜的字」的镜头里才第一次出现 |
| 天色 | 0 – 57 秒月夜；57 – 62.3 秒天渐渐亮；62.3 – 96.7 秒清晨；96.7 – 101 秒天黑下来；之后月夜 |
| 油灯 | 天亮时熄灭（清晨那段 `lamp` 为 0），天黑后重新亮着；130.4 – 149.8 秒那段由表演控制 |

### 山水（`kit.wild`）

`src/wild.js` 导出 `buildWild(renderer)`，返回：

| 字段 | 说明 |
|---|---|
| `scene` | 独立的 `THREE.Scene`，自带天、光、雾 |
| `clip` | 拍这个场景时镜头的近、远裁剪面 |
| `setSeason(name)` | `'春'` `'夏'` `'秋'` `'冬'`，立即切换。四季各有固定的时辰：春清晨、夏白天、秋黄昏、冬雪夜 |
| `setWeather(k)` | 0 到 1：1 是这个季节平常的样子（夏天下雨、冬天下雪、春秋飘花落叶），0 全停；超出范围会报错。夏天降到 0 是「雨停放晴」：雨先小，然后云开、斜阳出来，光、天色、雨雾一起变，出光束、虹和水汽 |
| `update(t)` | 每帧调 |
| `focus(point)` | 把投影的范围挪到这一点周围 |
| `heightAt(x, z)` | 地面（含路面、桥面）的高度 |
| `road` | 山路中线：`at(u)`、`dir(u)`（u 从 0 山顶到 1 山脚）、`length` |
| `cloudTop` | 云海顶面的大致高度 |
| `SHOTS` | 推荐机位：`[{ name, season, p, q }]` |

外景里小蟹高约 2 个单位，相当于一个行人。总调度在拍外景时自动切季节和天气、挪投影（挪到镜头看向的点）。
外景是一幅山水，远近都要看得清：背景的虚化只有书案的四成半（海边七成），`cam.blur` 是在这个基础上再乘；远近的层次靠空气里的霭。

- 山路全长约 1584，主峰顶高约 440（峰顶仍在 (0, 440, 0)，亭子在那里），湖面在 y = 0，云海顶面在 105 上下。`heightAt` 在石阶上是一级一级的（每级 0.36）。
- 山路分两大段。上半段是登山道（`wild/climb.js`，路程 0 到约 725，u 约 0 到 0.457），照真山的蹬道走：
  天街（山顶台地上的平街，0–42）→ 山门（约 37 处，路从券洞里过）→ 十八盘（42–325：夹在两道石壁之间的山沟里四折之字，每条腿三段梯段、段间有平台，梯段约 38°）
  → 崖下的台地（325–418，几级一歇）→ 歇脚的平台（418–439，有亭和碑）→ 鲫鱼背（439–505：46 个单位笔直连着的石阶，约 37°，两侧是崖，朱漆木栏）
  → 松林里的折返（505–688）→ 接回下半段（688–725）。全程 600 多级，平均坡度约 19°。下半段（小屋、桥、红叶石阶、湖边）的位置不随上半段变。
- 路面铺石全宽 6.8、每级高 0.36；折返的弯中线半径不小于 9.8（内侧 6.4）。路面上方 4 个单位以内、中线两侧 7.4 以内没有新摆的东西：山门券洞半宽 7.1，券脚离路面 4.3、券顶 7.7；横过路面的经幡最低处离路面 7 以上。
- 路边成排的东西（石灯、路碑、石凳、栏杆柱）按「里程」排（`wild/road.js` 的 `miles`）：接点的里程是定死的，所以下半段每样东西的位置不随上半段的长短变。
- `SHOTS` 的前四个依次是春、夏、秋、冬「小蟹在路上」的近景；`outside.js` 按季节和名字里的词来取机位，改名字时两边要一起改。
- 山下的地势（x 向东，z 向南）：主峰往东南、西南各伸出一臂山梁，把湖抱在怀里（湖心约 `[-20, 0, 925]`），两臂往南低下去，在 `z ≈ 1223` 让出水口；
  水口外一条谷往南去、往下走，两道谷壁夹着，约 `z = 1480` 以南沉进云里。云海不盖湖和水口这一带：水口外是一片「云湾」，云贴着谷底伸进来一条舌头；
  山梁上三个低垭口（方位约 76°、112°、257°，从湖心 `[0, 690]` 正北顺时针量）有云翻进来、顺着内坡往下淌。山梁外的支脉在云海里沉下去又冒出来，一直接到远山。
- 古道（出山的路）：`wild.scene.userData.scenery.sites.exit` 是它的中线，`[[x, y, z], …]`，从湖南岸的渡口村（约 `[9, 4.5, 1082]`）穿过水口、
  沿出谷东岸的坡脚往南，到约 `[87, -13, 1788]` 没进云里；相邻两点水平相距 4，`y` 是路面高度（就是该点的 `heightAt` 加 0.14）。
  约 `z = 1480` 以南路面在云舌里（云薄，越往南越厚）。路边的石灯在 `…sites.exitLamps`（`{ x, y, z, yaw }`，到 `z = 1470` 为止），水口有一座牌坊，路从中间穿过。
  山路的尽头（湖北岸）和古道的起点隔着湖，两者之间没有修路。

### 海边（`kit.shore`）

`src/shore.js` 导出 `buildShore(renderer)`，返回：

|---|---|

### 外景里蹦着走（`trek.js`）

`makeTrek(kit, land)`：`land` 是 `{ road: { at(u), dir(u), length }, heightAt(x, z) }`，不给就是山水的山路。
`walker({ u0, t0, speed, side, s, lag, treads, every, until, extra })` 返回 `poseAt(t)`：每 `every` 拍一蹦（不写是 .5，半拍一蹦；近景下石阶给 1，一拍一级），落点算准在踏面上。
`until`：蹦到这个时刻或之后的第一次落地就站住（正是 `poseAt.landing(until)` 那一次）。要它停下来的调用方必须给 `until`，并且停下以后继续拿 `poseAt(t)` 的姿势打底（`sq`、`pitch`、`lean`）：落地的缓冲和抵身上弹簧的压扁都在里面，自己另写 `sq` 会让身子在落地那一帧扁下去。
`speed` 是平路上的快慢；石阶上一蹦最多下 `treads` 级（不写是 1：一蹦一级，所以下石阶比平路慢；路面坑洼但不是台阶的地方给 `Infinity`）。
`poseAt.landing(t)` 给出 t 时刻或之后第一次落地的时刻和位置，要让它停下来时停在这一刻；`poseAt.landed(t)` 给出 t 时刻之前最近一次落地的时刻和位置。跟拍的镜头在这两个落点之间平滑滑过去，不跟着身子上下跳。

## 性能预算

- 离线逐帧渲染，不要求实时。整页加载在 15 秒内，单帧在 0.5 秒内（Apple 芯片笔记本）。
- 场景四个模块合计不超过 300 万个三角形；大量重复的东西用实例化。
- 程序生成的贴图单张不超过 2048×2048（宣纸的墨迹贴图可以到 4096×4096）。
- 点光源全场不超过 6 盏，都不投影。
